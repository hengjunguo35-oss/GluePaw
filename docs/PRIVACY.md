# 隐私设计

GluePaw 处理的是你复制过的所有内容——里面一定会有密码、验证码、私聊、身份证号。
所以隐私不是附加功能，而是这个项目存在的前提。

## 1. 三条原则

1. **能不记就不记**：私钥、云厂商密钥直接丢弃；敏感内容只进内存。
2. **记了就要锁好**：所有落盘内容加密，密钥由操作系统保护。
3. **删除要真删**：内存直接释放；数据库开启 secure_delete 并定期 VACUUM。

## 2. 数据分级

| 级别 | 例子 | 处理方式 |
| --- | --- | --- |
| DROP | `-----BEGIN PRIVATE KEY-----`、AWS Key、GitHub Token | 完全不记录 |
| MASK | 密码、验证码、银行卡号、身份证号、JWT | 隐私模式开启时只进内存并倒计时 |
| RECORD | 普通文本、链接、代码 | 加密写入数据库 |

识别顺序：

1. 剪贴板自带的「别记录」标记（密码管理器会写入，Windows `ExcludeClipboardContentFromMonitorProcessing`、
   macOS `org.nspasteboard.ConcealedType`、KDE `x-kde-passwordManagerHint`）
2. 内容正则匹配，命中即按最高风险处理
3. 银行卡号额外做 Luhn 校验，身份证号做校验位校验，尽量避免误判

## 3. 数据流向

```
复制内容
   │
   ├─ 命中「别记录」标记 ──────────────▶ 丢弃
   │
   ├─ 私钥类 ──────────────────────────▶ 丢弃
   │
   ├─ 敏感 + 隐私模式开 ──▶ 内存（会话密钥加密）──▶ 倒计时 ──▶ 删除 + 清剪贴板
   │
   └─ 其他 ──▶ Fernet 加密 ──▶ SQLite
```

全程没有网络请求。程序不包含任何 HTTP 客户端代码。

## 4. 密钥

```
Windows 登录态 ──DPAPI──▶ key.bin ──┬──▶ Fernet 加密 content
                                    └──▶ HMAC 生成 blind 索引
```

- 主密钥 32 字节，首次运行随机生成
- Windows 上用 DPAPI 加密后存盘，只有当前登录用户能解开
- 把 `vault.db` 和 `key.bin` 一起拷到另一台机器，也解不开
- 密钥丢失 = 历史永久不可恢复（这是设计的一部分，不是 bug）

## 5. 谁会看到你的数据

| 对象 | 能看到什么 |
| --- | --- |
| 你自己 | 全部（解密后） |
| 同一台电脑的其他用户 | 数据库文件，但解不开（DPAPI 绑定用户） |
| 云同步服务 | 什么都看不到——库文件在 `%LOCALAPPDATA%`，不在同步目录 |
| 网络上的任何人 | 什么都看不到——程序不联网 |
| 系统管理员 / 拿到你登录态的人 | 理论上可以解密，这超出应用层能防御的范围 |

## 6. 威胁模型

| 威胁 | 对策 | 残余风险 |
| --- | --- | --- |
| 恶意软件读取历史库 | 内容加密 + 密钥 DPAPI | 拿到你登录态的恶意软件仍可解密 |
| 笔记本丢失 | 全盘加密 + 应用层加密 | 无（假设磁盘加密开启） |
| 云同步泄露 | 库文件不放在同步目录 | 用户手动复制走则失效 |
| 屏幕共享时暴露 | 弹窗失焦自动隐藏、敏感内容打码 | 用户主动点「显示」后仍会暴露 |
| 密码被永久留存 | 敏感内容只进内存 + 倒计时 | 用户手动改标记或关闭隐私模式 |
| 备份软件抓取 | 敏感内容不落盘 | 普通内容仍会进备份 |
| 「删了」没删干净 | secure_delete + VACUUM | SSD 磨损均衡无法 100% 保证 |

## 7. 用户操作即授权

以下行为等于用户明确接管风险，程序会提示但不会阻止：

- 关闭隐私模式（弹窗说明后果）
- 把敏感内容标记为普通（未收藏时二次确认）
- 收藏敏感内容（确认后永久保存，但倒计时继续走）
- 关闭定期自动清理

## 8. 局限

- 程序无法防御已经拿到你 Windows 登录态的入侵者
- 系统级剪贴板云同步（Win+V、iCloud 通用剪贴板）不在本程序控制范围内，
  建议在系统设置里关闭
- 敏感识别基于正则，存在漏判与误判；重要场景请手动切换标记
- 未实现图片识别；截图类内容可能包含敏感信息却不会被拦截

## 9. 给使用者的建议

1. 保持 Windows 全盘加密（BitLocker）开启
2. 关闭 Win+V 的「跨设备同步」和 iCloud 通用剪贴板
3. 不要把 `%LOCALAPPDATA%\GluePaw` 放进 OneDrive 等同步目录
4. 定期在设置里清空一次历史
5. 处理敏感事务时用托盘菜单暂停记录（后续版本支持）
